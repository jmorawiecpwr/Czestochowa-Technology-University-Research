# Analiza dorobku Politechniki Częstochowskiej (ENG below)

Ten projekt to moja próba zabawy biblioteką TKinter do tworzenia prostych interfejsów, opakowując w nią analizę dorobku naukowego uczelni z mojego rodzinnego miasta - Częstochowy. Projekt obejmował następujące czynności związane z pracą z danymi:
1. Web scrapping z witryny Google Scholar
2. Preprocessing zebranych danych
3. Wytrenowanie prostych modelów regresyjnych, począwszy od standardowej regresji liniowej, po LSTM i ARIMA celem porównania wyników.

# Analysis of the Częstochowa University of Technology's Academic Output
This project is my attempt at playing around with the TKinter library for building simple interfaces, wrapping it around an analysis of the scientific output of the university from my hometown — Częstochowa. The project involved the following data-related tasks:
1. Web scraping from the Google Scholar website
2. Preprocessing of the collected data
3. Training simple regression models, ranging from standard linear regression to LSTM and ARIMA, in order to compare results.
